# Spells Glossary - 2014 Rules

An alphabetical reference to **305 spells** listed in [D&D Beyond’s Basic Rules (2014)](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/spells): 304 published descriptions plus Nystul’s Magic Aura, whose missing description is supplied from its SRD 5.1 equivalent.

Each spell links to its own note in `D&D 5E/Spells`, with its description, full material requirements, scaling rules where applicable, source links, and a backlink here. Spell text uses material shared with the openly licensed **SRD 5.1**, following the 2014 rules.

- **Level:** cantrip or spell level 1–9.
- **Components:** V = verbal, S = somatic, M = material. Materials, costs, and consumption appear in each note.
- **Casting Time:** reaction triggers and other qualifications appear in each note.
- **Concentration / Ritual:** whether concentration is required and whether the spell has the ritual tag. Ritual casting still requires an appropriate character feature.
- **Classes:** the chapter’s base class lists; subclass grants and later supplements are not included.
- Mordenkainen’s Sword, Otto’s Irresistible Dance, and Nystul’s Magic Aura appear in SRD 5.1 as Arcane Sword, Irresistible Dance, and Arcanist’s Magic Aura respectively.
