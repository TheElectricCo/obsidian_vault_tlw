# Spectator

[[Monsters Glossary|← Monsters Glossary]]

*Medium aberration, lawful neutral*

## Overview

A hovering aberration with four different eye rays: confusion, paralysis, fear, and necrotic injury. It can fire two different rays per turn, sustain itself magically, and redirect certain unsuccessful spells with its reaction.

> This note contains a factual reference and a brief ability summary. Use the linked 2014 Basic Rules entry for complete action wording, spell lists, saving throws, and durations.
