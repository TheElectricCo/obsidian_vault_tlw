# Flameskull

[[Monsters Glossary|← Monsters Glossary]]

*Tiny undead, neutral evil*

## Overview

A hovering undead skull that casts wizard spells and launches paired fire rays. It resists magic and can return after destruction unless its remains receive the specified treatment.

> This note contains a factual reference and a brief ability summary. Use the linked 2014 Basic Rules entry for complete action wording, spell lists, saving throws, and durations.
