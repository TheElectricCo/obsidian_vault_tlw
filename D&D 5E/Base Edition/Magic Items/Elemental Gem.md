# Elemental Gem

[[Magic Items Glossary|← Magic Items Glossary]]

*Wondrous item, uncommon*

## Item Details

- **Type:** Wondrous item
- **Rarity:** uncommon
- **Attunement:** No

## Description

This gem contains a mote of elemental energy. When you use an action to break the gem, an elemental is summoned as if you had cast the [[Conjure Elemental|conjure elemental]] spell, and the gem’s magic is lost. The type of gem determines the elemental summoned by the spell.

| Gem | Summoned Elemental |
| --- | --- |
| Blue sapphire | [[Air Elemental\|Air elemental]] |
| Yellow diamond | [[Earth Elemental\|Earth elemental]] |
| Red corundum | [[Fire Elemental\|Fire elemental]] |
| Emerald | [[Water Elemental\|Water elemental]] |
