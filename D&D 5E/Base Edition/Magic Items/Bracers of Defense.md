# Bracers of Defense

[[Magic Items Glossary|← Magic Items Glossary]]

*Wondrous item, rare (requires attunement)*

## Item Details

- **Type:** Wondrous item
- **Rarity:** rare
- **Attunement:** Yes

## Description

While wearing these bracers, you gain a +2 bonus to AC if you are wearing no armor and using no shield.
