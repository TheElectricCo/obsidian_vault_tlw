# Twig Blight

[[D&D 5E/Monsters Glossary|← Monsters Glossary]]

*Small plant, neutral evil*

## Overview

A small plant creature that resembles a dead shrub while still. It attacks with claws, perceives nearby creatures through blindsight, and is vulnerable to fire.

> This note contains a factual reference and a brief ability summary. Use the linked 2014 Basic Rules entry for complete action wording, spell lists, saving throws, and durations.
