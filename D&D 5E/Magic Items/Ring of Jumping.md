# Ring of Jumping

[[D&D 5E/Magic Items Glossary|← Magic Items Glossary]]

*Ring, uncommon (requires attunement)*

## Item Details

- **Type:** Ring
- **Rarity:** uncommon
- **Attunement:** Yes

## Description

While wearing this ring, you can cast the [[D&D 5E/Spells/Jump|jump]] spell from it as a bonus action at will, but can target only yourself when you do so.
