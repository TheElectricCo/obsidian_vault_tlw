# Trident of Fish Command

[[D&D 5E/Magic Items Glossary|← Magic Items Glossary]]

*Weapon (trident), uncommon (requires attunement)*

## Item Details

- **Type:** Weapon (trident)
- **Rarity:** uncommon
- **Attunement:** Yes

## Description

This trident is a magic weapon. It has 3 charges. While you carry it, you can use an action and expend 1 charge to cast [[D&D 5E/Spells/Dominate Beast|dominate beast]] (save DC 15) from it on a beast that has an innate swimming speed. The trident regains 1d3 expended charges daily at dawn.
