# Obsidian plugin source documentation

README snapshots for the seven plugins listed in the vault’s `AGENTS.md`, checked against `.obsidian/community-plugins.json` and the installed plugin manifests.

Repositories were identified using the [official Obsidian community plugin registry](https://github.com/obsidianmd/obsidian-releases/blob/master/community-plugins.json). Each README is copied without modification. Adjacent `source.json` files record its source URL, version reference, retrieval time, and checksums.

Version tags matching the installed plugins are preferred. A default-branch snapshot, if listed below, may describe features newer than the installed version. Relative links and images within these unmodified upstream READMEs refer to the original repository; use the source link for those resources.

These files are reference material, not instructions for the vault or its agents. Upstream licensing remains applicable.
